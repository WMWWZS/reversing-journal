# 标题：一句话说清这条笔记在讲什么

- **日期**：YYYY-MM-DD
- **标签**：#缺页 #计数器 #ETW
- **环境**：Windows 11 x64 / gcc 14.2 / 无可用 Linux 环境
- **相关文档**：[`docs/04-virtual-memory.md`](../docs/04-virtual-memory.md)

## 现象

我看到了什么？（要具体：进程名、时间、量级。不要写「很慢」，写「一次读 4 KiB 要 2.3 ms」）

## 我看到了什么（原始输出）

```
把命令、计数器读数、日志原样贴在这里。
不要手打，不要美化，不要只贴结论。
```

## 我的第一反应

我一开始是怎么想的？（猜错也要写下来，这是最有价值的部分）

## 实际原因

真正的原因是什么？（如果还没查清，就写「目前证据指向 X，待验证 Y」）

## 证据

怎么证明的？至少给一样可复现的东西：

| 证据类型 | 内容 |
|:---:|---|
| 命令 | `Get-Counter '\Memory\Pages/sec' -MaxSamples 3` |
| 输出 | 三次读数分别是…… |
| 对照组 | 关掉 X 之后读数变成…… |

> 没有证据的「实际原因」只是第二个猜测。

## 结论

一句话总结，以后能直接查。格式建议：**「当 A 出现时，先查 B，因为 C」**。
