# recon/ · 真实目标记录

每换一个真实目标，就在这个目录建一份 `recon-<名字>.md`（或直接沿用模板文件名）。

## 为什么要有这个目录

靶场里所有结论都能复现，因为靶子是我们自己写的、代码在手边。
**真实目标没有这个待遇**：你只有 exe、一个跑着的进程，和一堆数字。

所以真实目标的每一份记录都必须满足三条：

1. **能重算** —— 关掉游戏重开，按记录里的步骤能重新得到同一个字段（地址可以变，链不能变）。
2. **有数字** —— "找到了血量"不算结论；"当前值 87，游戏里显示 87"才算。
3. **写坑** —— 走错的路比走对的路更值钱，下次能省半小时。

## 模板

直接复制 [assaultcube-1.3.0.2.md](assaultcube-1.3.0.2.md) 的结构改。字段填不满就写"未验证"，
**不要猜**——猜出来的偏移会在关键时刻坑你。

## 字段类型先确认

真实游戏里血量可能是 `int32`、`float`，也可能是定点数（存的是"血量×100"）。
先各扫一遍，哪种收敛用哪种；这也决定了 `config.txt` 里 `type=` 写什么。
