# 07 · 反作弊：威胁模型与防护设计

> 这是这个仓库的**最终目的地**。
> 前面所有分析的目的是：知道攻击从哪里来，才能知道防在哪里。

## 核心认知（先记住这四条）

1. **客户端永远不可信。** 只要有足够价值，客户端防护必然被突破。
2. **防护目标是提高成本 + 提高检测概率**，不是「绝对防住」。
3. **只做客户端 = 必然被破。** 真正的边界在服务端。
4. **检测「不可能的行为」比检测「工具」更稳。** 工具会变，物理定律不会。

---

## 攻击面枚举

| 层级 | 攻击手段 | 典型目的 |
|---|---|---|
| 内存 | 读/写进程内存 | 透视、改血量、改金钱 |
| 代码 | DLL 注入、Inline Hook、代码洞 | 改逻辑、去限制 |
| 调试 | 附加调试器、硬件断点 | 分析、动态改值 |
| API | Hook 图形 API / 输入 API | 透视渲染、模拟输入 |
| 驱动 | 内核级读写、句柄获取 | 绕过用户态保护 |
| 输入 | 模拟键鼠、宏 | 自瞄、连点 |
| 网络 | 封包篡改、重放、延迟 | 改数值、卡位 |
| 环境 | 虚拟机、模拟器、多开 | 批量账号、绕过硬件封禁 |

---

## 防护手段（按投入产出比排序）

### 第一层：服务端权威 ★★★★★

**这是唯一真正有效的一层。**

- 位置、速度、加速度合理性校验
- 命中判定、伤害结算在服务端做
- 经济、掉落、CD 全部服务端裁决
- 客户端只做「表现」，不做「裁决」

> 为什么排第一：这一层不需要和攻击者打军备竞赛，它是架构层面的正确性。

### 第二层：客户端完整性 ★★★☆☆

| 手段 | 说明 | 局限 |
|---|---|---|
| 代码段哈希校验 | 检测内存补丁 | 校验逻辑本身可被绕过 |
| 数字签名 | 检测文件篡改 | 运行时内存改动检测不到 |
| 反调试 | PEB 检查、硬件断点寄存器、时间差、异常链 | 可被对抗 |
| 反注入 | 模块枚举、线程枚举、未签名模块检测 | 内核级注入难防 |
| 反 dump | 页保护、影子副本比对 | 影响性能 |
| 多实例检测 | 互斥体、窗口枚举、进程扫描 | 可被改名绕过 |

> 这一层的定位是**提高门槛**，不是防线。要接受「会被绕过」这个前提。

### 第三层：混淆与虚拟化 ★★☆☆☆

- VMProtect / Themida / 自研 VM
- 控制流平坦化、字符串加密、虚假分支
- 目标：让静态分析成本上升到不划算

**代价**：性能下降、崩溃率上升、你自己的调试也变难。

### 第四层：内核级防护 ★★☆☆☆（高风险）

- 句柄剥离（`ObRegisterCallbacks`）
- 进程/线程/模块回调
- ETW 监控
- Hypervisor 级（如 Vanguard）

**代价极高**：兼容性崩溃、隐私争议、开发与维护成本。只有大型商业项目才值得。

### 第五层：行为检测与遥测 ★★★★☆

- 统计异常检测（命中率、反应时间、移动轨迹）
- 机器学习模型
- 举报 + 人工复核
- 封禁策略：延迟封禁、批次封禁（避免暴露检测点）

> **这一层常常被低估，但它是唯一能对付「未知新工具」的手段。**
> 检测行为而不是检测工具，是持久战的正确姿势。

## 威胁建模练习

对任意一种作弊手法，问这四个问题：

1. **它必须接触哪一层？**（内存 / 代码 / 网络 / 输入）
2. **它会在哪里留下痕迹？**（异常读写、异常时序、异常数值）
3. **检测成本 vs 绕过成本，哪边低？**
4. **误封风险有多大？**（正常玩家会不会被误判）

### 示例：自瞄

| 问题 | 分析 |
|---|---|
| 接触层 | 内存读（敌人坐标）+ 输入模拟（鼠标移动） |
| 痕迹 | 瞄准轨迹过于平滑、反应时间低于人类极限、爆头率异常、准星移动不符合人手抖动模型 |
| 检测成本 | 低（纯服务端统计即可） |
| 误封风险 | 中（职业选手数据异常，需要人工复核） |

> 注意：自瞄的**行为特征**在服务端就能统计，不需要任何客户端检测。这就是「服务端权威」的价值。

---

## 防护设计检查清单

设计一套防护方案时，逐条确认：

- [ ] 关键裁决是否在服务端？
- [ ] 客户端发来的数据是否全部按不可信处理？
- [ ] 检测手段的误封率是否可接受？
- [ ] 是否有对抗「未知新工具」的手段（行为检测）？
- [ ] 封禁策略是否会暴露检测点？（建议延迟、批量）
- [ ] 性能开销是否可接受？
- [ ] 隐私合规是否满足？（尤其内核级方案）
- [ ] 是否有降级方案？（检测失败时不影响正常玩家）
