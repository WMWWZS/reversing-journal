# Writeups · 题解

> 每做完一个题目，在这里留一篇。**没有写题解，就等于没做过。**

## 什么算一个 writeup

- crackme 题解
- CTF 逆向 / Pwn 题
- 对某个单机游戏的分析记录
- 对某个保护方案的研究

## 命名规则

```
目标名-简短描述.md
```

例如：

```
crackmes-easy-01-明文比较.md
unity-il2cpp-某单机游戏-实体结构还原.md
vmp-反调试机制观察.md
```

## 必须包含

1. **目标信息**：文件哈希、平台、难度
2. **侦察结论**：编译器、是否加壳、引擎
3. **分析过程**：怎么一步步定位的（重点，别只写结果）
4. **关键地址**：每个结论都要能指回具体地址
5. **收获**：学到了什么新东西

模板见 [`_TEMPLATE.md`](_TEMPLATE.md)。
