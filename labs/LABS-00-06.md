# labs 00-06 · 内存分析主线（2026-11 增补）

这一组实验回答一个问题：**一个进程怎样碰另一个进程的内存**。全部在自建靶子上跑，
每一步都有可复现的数字。

| 目录 | 回答的问题 | 关键结论 |
|---|---|---|
| [00-memory-model](00-memory-model) | 地址 / 偏移 / 字节 / 跨进程读，到底是什么 | 地址是格子编号；偏移是加法；float 4 字节低位在前；`ReadProcessMemory` = memcpy + handle |
| [02-find-offset](02-find-offset) | 没有源码怎么把偏移挖出来 | 整映像扫描 + 五条互相印证的证据链 |
| [03-write-memory](03-write-memory) | 怎么跨进程写，并且让它留住 | 三件套权限；数值被重算就得循环写 |
| [04-pointer-chain](04-pointer-chain) | 地址每次启动都变怎么办 | 指针 = 装地址的格子；链 = 每跳读 8 字节 + 加偏移；必须扫全进程内存 |
| [05-aob-scan](05-aob-scan) | 更新后偏移失效怎么办 | 扫访问指令（`48 8B 05 disp32`），`目标 = 指令 + 7 + disp`，候选必须验证 |
| [06-inject](06-inject) | 怎么让目标自己改自己 | `VirtualAllocEx` + `WriteProcessMemory` + `CreateRemoteThread`；非易失寄存器 + 栈对齐 |

> 01-struct-layout 沿用仓库原有那一套（Player 结构体 / player.h）；本组实验里的
> `01/entity.h` 是 02-06 依赖的最小结构体定义，两套并存互不影响。
