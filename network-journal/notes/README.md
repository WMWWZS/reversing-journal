# Notes · 零散笔记

> 系统的知识放 `docs/`，这里放**还没想清楚的东西**。

## 什么该放这里

- 抓包时遇到的怪现象
- 还没验证的猜想
- 踩坑记录（命令报错、工具坑、环境坑）
- 一句话的灵感
- 一次延迟排查的原始时间线

## 什么不该放这里

- 能从 RFC 直接抄到的定义（放 `docs/`）
- 没有证据的结论（先补证据，再写）
- 大段抓包文件（用过滤器 + 包序号描述，pcap 不入库）

## 命名规则

```text
YYYY-MM-DD-简短标题.md
```

例如：

```text
2026-11-22-dns-707ms-before-any-packet.md
2026-11-23-close-wait-in-my-listener.md
2026-11-23-curl-http2-not-supported-build.md
```

## 写笔记的要求

1. **带证据**：包序号、过滤器、字段值、命令输出，至少给一个；
2. **带第一反应**：先写「我以为是什么」，再写「实际是什么」，反差才是学习点；
3. **结论可检索**：最后一句话要能当关键词搜到。
