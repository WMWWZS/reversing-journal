===== what this demonstrates =====
The client always sends ATTACK damage=5.00 and its own claimed_hp (95,90,85,80,75).
tap.py --hack-claimed X rewrites those 4 payload bytes on the wire (frame length unchanged).
With --trust-client the server stores that number as the real hp: the client decides its own hp.
With --authoritative the same rewritten packet changes nothing: the server recomputes hp itself.
