===== what to look at =====
SNAPSHOT count=1000 is ONE frame of 16006 bytes (6-byte header + 16002-byte payload).
D1: the server writes it with 4 send() calls (4096,4096,4096,3718). The client recv buffer
    is 8192, so recv() has to be called several times to assemble that one frame.
D2: the server writes it with ONE send(); the client recv buffer is 65536, so one recv()
    returns all 16006 bytes at once.
Both are legal: TCP gives you a byte stream, not messages. That is why the parser keeps a
buffer and only cuts a frame once total_len bytes have arrived.
